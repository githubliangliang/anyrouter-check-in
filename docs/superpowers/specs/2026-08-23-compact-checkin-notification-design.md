# 紧凑签到通知模板设计

## 目标

压缩 `checkin.py` 的通知正文，减少钉钉、邮件等渠道中的冗余换行，同时保留账号、余额变化、签到奖励、失败原因、执行时间和统计结果。

## 格式

每个有余额明细的成功账号占一行：

```text
账号1 | 余额 $12.00 -> $13.00 | 签到 +$1.00
```

签到奖励为零时显示 `已签到`：

```text
账号2 | 余额 $8.00 -> $8.00 | 已签到
```

失败账号保留一行账号和脱敏后的失败原因。通知顶部为执行时间，底部为成功/失败统计；不显示累计消耗，不使用分隔线或空白段落。调试截图提示继续作为末行追加。

## 行为边界

- 仅修改通知文本格式，不改变签到请求、余额计算、通知触发条件或通知渠道。
- 余额前后值和签到奖励继续保留两位小数。
- 现有异常脱敏和令牌保护规则保持不变。

## 测试验收

- 成功账号通知包含单行余额和签到奖励，不包含“消耗”或 `usage_increase` 文本。
- 零奖励账号显示 `已签到`。
- 多账号通知不含账号间空白分隔行。
- 失败原因、执行时间、统计结果和截图提示仍能出现在通知中。
